# Руководство пользователя Shelly 1.0.11

[English version](USER_GUIDE.md) · [README](../README.md) · [CHANGELOG](../CHANGELOG.md)

Shelly — портативный запускатель PowerShell-скриптов для Windows. Он показывает все `.ps1` из папки `Scripts` и
запускает каждый скрипт в нужном ему движке (Windows PowerShell 5.1 или PowerShell 7). Shelly читает параметры
скрипта, предупреждает об опасных командах, ведёт историю запусков и собирает скрипты в `.exe`.

## 1. Установка и требования

**Требования**

- Windows 10 или 11, x64. Полное оформление (скруглённые углы, Mica, цветной заголовок) есть только в Windows 11. В
  Windows 10 Shelly работает с упрощённым оформлением.
- Windows PowerShell 5.1, он входит в Windows. PowerShell 7 необязателен: он нужен только скриптам, которые его
  требуют (см. [раздел 12](#12-установка-powershell-7)).
- Для **Собрать .exe** нужен компилятор C# из .NET Framework 4
  (`%WINDIR%\Microsoft.NET\Framework64\v4.0.30319\csc.exe`). Он есть в Windows 10/11.

**Две сборки**

| Файл | `Shelly.exe` | Нужно |
|---|---|---|
| `shelly-<версия>.zip` (рекомендуется) | ≈ 2 МБ | [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0) (x64) |
| `shelly-<версия>-selfcontained.zip` | ≈ 70 МБ | ничего: среда выполнения внутри exe (запускается чуть медленнее) |

Если среды выполнения нет, при первом запуске малой сборки Windows покажет окно со ссылкой на загрузку. Можно
установить её и командой `winget install Microsoft.DotNet.DesktopRuntime.10`.

**Установка.** Распакуйте архив куда угодно (например, в `C:\Tools\Shelly`) и запустите `Shelly.exe`. Установщика нет.

**Обновление с 0.9.x (версия на PowerShell).** Положите `Shelly.exe` в старую папку Shelly, рядом с `Scripts` и
`launcher-settings.json`. Избранное, выбранные движки, запомненные параметры запуска, доверенные скрипты, история и
остальные настройки читаются как есть. Ключи, которых Shelly 1.0 не знает, сохраняются в файле. Shelly работает и
тогда, когда exe лежит в старой подпапке `build\`: если в ней нет своей папки `Scripts`, а у родительской папки есть,
папкой Shelly считается родительская.

**Где что хранится**

| Что | Где |
|---|---|
| Скрипты | `<папка Shelly>\Scripts\` |
| Настройки | `<папка Shelly>\launcher-settings.json` |
| История запусков | `<папка Shelly>\launcher-history\` (`history.json` и по файлу `<id>.log` с выводом на каждый запуск) |
| Собранные .exe | `<папка Shelly>\build\` |
| Выбранные значки скриптов | `<папка Shelly>\assets\script-icons\` |
| Журнал, кэш анализа, журнал замеров | `%TEMP%\Shelly\` (`shelly.log`, `analysis-cache.json`, `perf.log`) |
| Автозапуск (только если включён) | `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`, значение `Shelly` |

Больше Shelly ничего не пишет за пределами своей папки.

## 2. Первый запуск и структура папок

**Предупреждение.** При самом первом запуске Shelly показывает короткое предупреждение: скрипты выполняются с правами
вашей учётной записи (от администратора — с полным контролем после запроса UAC), Shelly — не песочница, проверка
безопасности — это ограждение и может что-то пропустить, запускайте только скрипты, которым доверяете и которые
прочитали, авторы не отвечают за ущерб от скриптов. **Понятно** продолжает работу (больше окно не появится),
**Выйти** закрывает Shelly. Перечитать его можно в **Параметры → О программе → Предупреждение**.

При запуске Shelly создаёт `Scripts`, `build` и `%TEMP%\Shelly`, если их нет. Для одной папки работает только один
Shelly. Если запустить его второй раз, на передний план выйдет первое окно, а аргумент `--run` будет передан ему.

```
Shelly\
  Shelly.exe
  Scripts\                 ваши скрипты; подпапки становятся группами
    usd_rub.ps1
    Examples\Hello with parameters.ps1
    Examples\Chris Titus WinUtil.ps1
    System\System summary.ps1
  build\                   собранные .exe (с теми же подпапками, что в Scripts)
  assets\shelly.ico        значок .exe по умолчанию
  assets\script-icons\     выбранные значки скриптов
  launcher-settings.json   настройки (создаётся при первом запуске)
  launcher-history\        история запусков
```

- В список попадают все `*.ps1` из `Scripts`, до 8 уровней вложенности. Shelly пропускает файлы и папки, чьи имена
  начинаются с точки, скрытые файлы и папки, а также ссылки на папки (junction и symlink).
- Каждая подпапка — сворачиваемая **группа**. Скрипты прямо в `Scripts` попадают в группу **Общие**. Скрипты со
  звёздочкой дополнительно показаны в группе **Избранное** сверху.
- Список следит за папкой: файлы, добавленные, переименованные или удалённые вне Shelly, появляются и исчезают сами.
  **F5** обновляет список вручную.

**Командная строка**

| Аргумент | Действие |
|---|---|
| `--run "Папка\Скрипт.ps1"` (или `-run`, `/run`) | Запускает скрипт, путь указывается относительно `Scripts`. Этим пользуется список переходов. |
| `--minimized` (или `-minimized`, `/minimized`, `--tray`) | Запуск скрытым в трей. Этим пользуется автозапуск. |
| `--perf` | Записывает замеры времени запуска в `%TEMP%\Shelly\perf.log`. |

## 3. Главное окно

**Панель навигации** (слева): **Скрипты** (Ctrl+1), **Избранное** (Ctrl+2), **История** (Ctrl+3), **Совместимость**,
**Параметры** (Ctrl+,). Ctrl+M или кнопка ☰ сворачивает панель до значков. Если окно уже 800 px, панель остаётся
значками и открывается поверх страницы; Esc закрывает её.

**Страница «Скрипты»**

- Панель инструментов в заголовке, слева от поиска: **Новый скрипт**, **Новая папка** | **Сортировка**, **Свернуть
  все / Развернуть все**, **Вид**, **Фильтр**. Дальше **омнибокс** (поиск и команды `>`, см.
  [раздел 8](#8-команды-омнибокса)), а справа от него **Обновить** (F5) и **Открыть папку** (Scripts, build или
  Shelly). У каждой кнопки есть подсказка.
- В узком окне сначала сужается поле поиска. Потом Сортировка, Свернуть, Вид и Фильтр уходят в меню **…** (Ещё). И
  только после этого поле поиска превращается в кнопку.
- **Сортировка** (кнопка ⇅): Имя, Дата изменения, Последний запуск или Число запусков; По возрастанию или По убыванию.
  Порядок действует внутри каждой группы, а Избранное остаётся отдельной группой сверху. При равенстве скрипты идут по
  имени. При сортировке по последнему запуску скрипты, которые ни разу не запускались, всегда в конце. Число запусков
  считается по истории (см. **Хранить запусков** в Параметрах). Если порядок не «Имя, по возрастанию», значок кнопки
  окрашен в цвет акцента. Выбор сохраняется.
- **Свернуть все / Развернуть все** — одна кнопка. Пока открыта хоть одна группа, она сворачивает все группы
  (Избранное, скрипты в корне и все папки), иначе разворачивает все. Клавиши: **Ctrl+Shift+[** и **Ctrl+Shift+]**.
  Состояние групп сохраняется, как и раньше. Во время поиска кнопка недоступна: результаты идут плоским списком.
- **Вид**: **Карточки** (обычные карточки высотой 64 px) или **Компактный список** (одна строка 40 px на скрипт:
  значок, имя, рядом серым описание, отметки состояния и кнопки при наведении; без рамки карточки). Выбор сохраняется.
- **Фильтр**: отметьте любые из пунктов **Уже запускались**, **Ни разу не запускались**, **Нужен PowerShell 5.1**,
  **Есть предупреждения безопасности**, **Запуск от администратора (запомненный режим)** и **Только избранное**.
  «Уже запускались» и «Ни разу не запускались» дополняют друг друга, остальные фильтры сужают список. Фильтры работают
  вместе с поиском. Показываются только группы, в которых есть подходящие скрипты. С «Только избранное» отдельной
  группы «Избранное» нет. Пока фильтр включён, на кнопке горит точка цвета акцента, а под заголовком появляется плашка
  **Фильтры: N · Сбросить** (в подсказке список фильтров). Если ничего не подошло, страница пишет **Нет скриптов под
  эти фильтры** и предлагает **Сбросить фильтры**. Фильтры действуют до закрытия Shelly и не сохраняются.
- Поиск ищет по имени, папке и описанию. Если ввести несколько слов через пробел, совпасть должны все.
- **Строки скриптов.** В строке видны значок, имя и описание. При наведении появляются ▶ **Запустить** и ⚙
  **Параметры запуска**. Пока скрипт работает, в строке крутится индикатор, идёт время и есть кнопка ⏹ **Остановить**.
  Слева от кнопок — неброские отметки:
  - **PS 5.1** или **PS 7** — движок. Отметка видна, только когда она что-то сообщает: скрипт идёт в Windows
    PowerShell 5.1, движок выбран вручную или нужный движок не установлен. Для «Авто → 7» отметки нет. Подсказка
    объясняет, почему «Авто» выбрал этот движок.
  - **Безопасность**: красный щит — опасно, жёлтый — внимание (находки «инфо» отметки не дают). Оранжевая **стрелка
    загрузки** — файл скачан из интернета и заблокирован, пока его не разблокировать. Часы — PowerShell ещё проверяет
    скрипт; вопросительный знак — ни один PowerShell не смог его проверить. В подсказке перечислены находки, а для
    скачанных файлов — адрес. См. [раздел 6](#6-проверка-безопасности).
  - **Последний результат** — успех, ошибка (с кодом выхода), остановлен или окно закрыто. Подробности в подсказке.
- Подсказка строки: относительный путь, параметры (`*` = обязательный) и время изменения файла.
- Двойной щелчок или Enter запускает скрипт. Правый щелчок открывает меню: Остановить (во время работы), Запустить,
  Запустить в отдельном окне, Запустить от администратора, Параметры запуска…, Изменить, Открыть во внешнем редакторе,
  Собрать .exe, В избранное / Убрать из избранного, Сменить значок…, Значок по умолчанию (если выбран свой), Показать
  запуски (последний запуск в истории), Переименовать, Открыть расположение файла, Копировать путь, Удалить.
- Правый щелчок по группе или пустому месту: Новый скрипт здесь, Новая папка, Переименовать папку, Удалить папку,
  Открыть в проводнике.
  Удаление спрашивает подтверждение, затем отправляет скрипты и непустые папки в Корзину.
- **Панель вывода** (снизу): вывод выбранного запуска в реальном времени. Кнопки: Остановить, Запустить снова, Открыть
  скрипт, Копировать, Сохранить в `.txt`, Очистить вид (в истории вывод остаётся), Перенос строк, Найти (Ctrl+F).
  Разделитель меняет высоту панели, шеврон сворачивает её.
- **Информационная полоса** появляется, если вышло обновление, если скриптам нужен отсутствующий PowerShell 7
  (**Установить**) или если есть замечания о совместимости. Её можно закрыть.

**Страница «Избранное».** Плитки скриптов со звёздочкой с кнопками Запустить, Параметры запуска и Остановить. Двойной
щелчок по плитке запускает скрипт. Звёздочка ставится и снимается через Ctrl+D или контекстное меню. Избранное
показано также в меню трея и в списке переходов на панели задач.

**Страница «История».** Здесь все запуски: обычные, в отдельном окне, от администратора, из трея, из редактора и
повторные. У каждого видны результат, время начала, длительность, движок, режим и параметры. Есть фильтр (Все запуски,
Успешные, С ошибкой, Остановленные, В отдельном окне) и поиск. Выберите запуск, чтобы увидеть сохранённый вывод.
**Enter** повторяет запуск с теми же параметрами, режимом и движком. **Del** удаляет запись. **Очистить историю**
удаляет всё, кроме идущих запусков. Запуски в отдельном окне вывод не сохраняют.

**Страница «Совместимость».** Проверяет Windows, .NET, на котором работает Shelly, Windows PowerShell 5.1, PowerShell 7
(с кнопками **Установить PowerShell 7…** и **Проверить снова**), политику выполнения из групповой политики, анализ
скриптов, компилятор C# для сборки exe, .NET Framework 4 (нужен 4.5 или новее, рекомендуется 4.8), горячую клавишу
и значок в трее. Для каждой проверки показаны состояние и подсказка.

**Страница «Параметры».** См. [раздел 14](#14-справочник-параметров).

## 4. Запуск скриптов

**Режимы**

| Режим | Что происходит |
|---|---|
| **Обычный** | Скрипт работает скрыто, вывод идёт в панель вывода. Рабочая папка — папка скрипта. |
| **Отдельное окно** | Консоль PowerShell, которая остаётся открытой после завершения скрипта (`-NoExit`). |
| **От администратора** | То же, но с повышением прав через UAC. Перед таким запуском Shelly всегда спрашивает (см. [раздел 6](#6-проверка-безопасности)). |

Все запуски идут с `-NoProfile -ExecutionPolicy Bypass`. Обычные запуски, кроме того, идут с `-NonInteractive` и
закрытым вводом, поэтому скрипты, которые что-то спрашивают (`Read-Host`, запросы), нужно запускать в отдельном окне.
Вывод обычного запуска — простой текст, без ANSI-цветов.

**Какой режим используется**

- ▶, Enter, двойной щелчок и список переходов берут запомненный для скрипта режим, а если его нет — обычный.
- Пункты контекстного меню используют свой режим.
- Избранное в меню трея всегда запускается в отдельном окне.
- **F5** в редакторе запускает скрипт в обычном режиме.

**Движки.** Для каждого скрипта выбирается **Авто**, **5.1** или **7**. В режиме «Авто» Shelly выбирает:

1. PowerShell 7, если в скрипте есть `#Requires -Version 6` и выше или `#Requires -PSEdition Core`.
2. Windows PowerShell 5.1 при `#Requires -PSEdition Desktop` или `#Requires -Version` 5.x и ниже.
3. PowerShell 7, если скрипт использует возможности только семёрки: `??`, `??=`, `?.`, `?[]`, `&&`, `||`, тернарный
   `? :`, `clean { }`, `$PSStyle`, командлеты и параметры только из 7 (например, `ForEach-Object -Parallel`), или если
   скрипт разбирается только в 7.
4. Windows PowerShell 5.1, если скрипт использует команды только из 5.1 (например, `workflow` или
   `Get-Content -Encoding Byte`), или если он разбирается только в 5.1.
5. Иначе — параметр **Движок по умолчанию для «Авто»**. По умолчанию это «PowerShell 7, если установлен, иначе 5.1».

Движок можно закрепить за скриптом в **Параметрах запуска**. Выбор сохраняется сразу после изменения. Если выбранного
движка нет, скрипту нужны права администратора или не установлен нужный модуль, Shelly сообщит об этом до запуска. Он
предложит выход (другой движок, запуск от администратора, установку PowerShell 7) или **Всё равно запустить**.

**Параметры запуска** (⚙, Ctrl+I или Ctrl+Enter, или контекстное меню) — компактный диалог:

- значок, имя и описание скрипта;
- поле для каждого параметра. Подсказка в поле показывает значение по умолчанию, «задаёт скрипт» для вычисляемого
  значения или тип («число», «текст»…). Пустое поле не передаётся, и скрипт берёт своё значение по умолчанию.
  Переключатели (`[switch]`) и `[bool]` — флажки. `ValidateSet` — выпадающий список. Обязательные параметры отмечены
  красной `*`. Во всплывающей подсказке — тип, «обязательный», значение по умолчанию и `HelpMessage`. Массивы
  (`[string[]]`) вводятся списком через запятую;
- рядом друг с другом **PowerShell: Авто (x) / 5.1 / 7** и **Режим: Обычный / Отдельное окно / От администратора**;
- последний запуск в одну строку со ссылкой **Показать в истории**;
- предупреждения, если они есть;
- **Запомнить для скрипта**, **Запустить** и **Отмена**.

Если **Запомнить** отмечен, кнопка «Запустить» сохраняет параметры и режим, и дальше ▶ / Enter / двойной щелчок
используют их. Если снять флажок и нажать «Запустить», запомненное забывается. Если у обязательного параметра нет
значения, запуск откроет этот диалог вместо скрипта, а кнопка «Запустить» в нём скажет, каких полей не хватает.

**Одновременные запуски.** Несколько скриптов могут работать одновременно, у каждого свой вывод, индикатор и кнопка
«Остановить». Один и тот же скрипт в обычном режиме может идти только в одном экземпляре; запуски в отдельном окне не
ограничены. За окнами (в том числе от администратора) Shelly следит до их закрытия. За окном с повышенными правами
следить иногда нельзя, тогда запуск записывается как «запущен».

**Остановка.** ⏹ в строке или на плитке, кнопка «Остановить» в панели вывода или контекстное меню. Остановка завершает
всё дерево процессов скрипта. Если при выходе из Shelly ещё идут обычные запуски, Shelly спросит и остановит их.

**Вывод.** Панель показывает не больше 4 МБ или 100 000 строк одного запуска и отмечает, что остальное пропущено. В
истории хранится вывод в пределах параметра **Сохранять вывода на запуск**. Если вывод длиннее, сохраняются начало и
последние строки.

**Повтор из истории.** На странице «История» нажмите Enter или **Запустить снова с теми же параметрами**. То же делает
кнопка «Запустить снова» в панели вывода.

## 5. Как писать скрипты для Shelly

**Описание.** Под именем (в компактном списке — рядом с ним) Shelly показывает однострочное описание. Оно берётся из
комментариев в начале скрипта, до начала кода; используется то, что встретится первым:

- однострочный комментарий `#` среди первых 8 строк. Строки `#Requires`, `#!` и `# Shelly-…:` пропускаются. Префикс
  `Описание:` (или `Description:`) отбрасывается, так что `# Описание: Чистит temp` покажет «Чистит temp»;
- `.SYNOPSIS` из блока справки `<# … #>` в начале файла (в пределах первых 60 строк). Берётся первый абзац после
  `.SYNOPSIS`, до следующего ключевого слова вроде `.DESCRIPTION`. Блок справки без `.SYNOPSIS` пропускается.

```powershell
<#
.SYNOPSIS
    Сохраняет профиль пользователя в zip-архив.
.DESCRIPTION
    Длинный текст, который Shelly не показывает.
#>
param([string]$Target = "D:\Backup")
```

Шаблон **Нового скрипта** начинается со строки `# Что делает этот скрипт` — замените её своей.

**Параметры.** Shelly в фоне разбирает блок `param()` настоящим парсером PowerShell. Пока разбор не готов, работает
быстрый встроенный разборщик.

| В скрипте | В параметрах запуска | Передаётся как |
|---|---|---|
| `[string]$Name` | поле («текст») | `-Name 'значение'` |
| `[int]$Count = 3` (любой числовой тип) | поле с подсказкой `3` | `-Count '5'` |
| `[datetime]$When` | поле («дата») | `-When '…'` |
| `[switch]$Loud` | флажок | `-Loud` (если по умолчанию `$true`, а флажок снят, передаётся `-Loud:$false`) |
| `[bool]$Flag` | флажок | `-Flag:$true` / `-Flag:$false` |
| `[string[]]$Items` | поле («список через запятую») | `-Items 'a','b'` |
| `[ValidateSet('A','B')]` | выпадающий список, первым идёт «(по умолчанию)» | `-Param 'A'` |
| `[Parameter(Mandatory)]` | красная `*`; пока поле пустое, запуск не начнётся | |
| `[Parameter(HelpMessage = '…')]` | текст подсказки | |

**Значок.** Строка в начальных комментариях задаёт значок по умолчанию: код символа Segoe Fluent Icons из области
частного использования (`E000`–`F8FF`):

```powershell
# Shelly-Icon: E9D2
```

- Строка должна стоять в начальном блоке комментариев, в первых 40 строках. Перед ней может быть блок справки
  `<# … #>`.
- Подходят и записи `U+E9D2`, `0xE9D2`, `&#xE9D2;`, `\uE9D2`.
- В примерах используются `E9D2` (usd_rub), `E77B` (Hello with parameters), `E977` (System summary) и `E90F` (Chris Titus WinUtil). Коды символов
  есть в документации Microsoft «Segoe Fluent Icons font».
- Картинка, выбранная через **Сменить значок…** (`.ico` или `.png`), важнее строки. Она копируется в
  `assets\script-icons`.

**Режим запуска по умолчанию.** `# Shelly-Mode: inline`, `window` или `admin` в начальных комментариях задаёт, как
скрипт запускается двойным щелчком, клавишей Enter и из списка переходов, пока в «Параметрах запуска» не запомнен
другой режим. Запуск от администратора всё равно требует подтверждения и показывает запрос UAC.

**Кодировка.** Windows PowerShell 5.1 читает `.ps1` без BOM как ANSI, и русский текст превращается в кракозябры.
Сохраняйте скрипты в **UTF-8 с BOM**. Редактор Shelly всегда сохраняет так, и новые скрипты создаются так же.

**Код выхода.** Обычный запуск завершается с кодом из `exit N` скрипта, или с кодом последней внешней программы, или с
1 после прерывающей ошибки, иначе с 0. Shelly считает 0 успехом, остальное — ошибкой.

**Полный пример**

```powershell
# Копирует файлы одного типа из одной папки в другую.
# Shelly-Icon: E8C8
#Requires -Version 5.1

param(
    [Parameter(Mandatory = $true, HelpMessage = 'Откуда копировать')]
    [string]$Source,

    [Parameter(Mandatory = $true, HelpMessage = 'Куда копировать')]
    [string]$Destination,

    [ValidateSet('txt', 'log', 'csv')]
    [string]$Extension = 'txt',

    [int]$MaxFiles = 100,

    [switch]$WhatIf
)

$files = Get-ChildItem -LiteralPath $Source -Filter "*.$Extension" -File | Select-Object -First $MaxFiles
if (-not $files) { Write-Host "В $Source нет файлов .$Extension"; exit 1 }

New-Item -ItemType Directory -Path $Destination -Force | Out-Null
foreach ($f in $files) {
    if ($WhatIf) { Write-Host "Будет скопирован $($f.Name)" }
    else { Copy-Item -LiteralPath $f.FullName -Destination $Destination; Write-Host "Скопирован $($f.Name)" }
}
Write-Host "Готово: файлов $($files.Count)."
```

В списке скрипт будет с описанием «Копирует файлы одного типа из одной папки в другую.» и значком копирования. В
параметрах запуска появятся Source * и Destination * (обязательные), Extension в виде списка, MaxFiles с подсказкой
100 и флажок WhatIf. Сохраните файл в UTF-8 с BOM: в нём есть русский текст.

## 6. Проверка безопасности

> **Ограждение, а не песочница.** Shelly читает скрипт перед запуском и предупреждает об опасных командах. Он ничего
> не изолирует и не ограничивает: скрипт выполняется с вашими правами (от администратора — с полным контролем над
> компьютером). Проверка может что-то пропустить. Запускайте только скрипты, которым доверяете и которые прочитали.

### Как работает проверка

Shelly разбирает скрипт собственным парсером PowerShell (AST) в PowerShell 7 или Windows PowerShell 5.1 и смотрит на
команды, которые реально выполнятся, а не на текст:

- **Имена команд** берутся из разобранной команды. Псевдонимы раскрываются по полной встроенной таблице 5.1 и 7
  (`rm`, `ri`, `del`, `erase`, `rd`, `rmdir`, `iwr`, `irm`, `iex`, `curl`, `wget`, `sal`…), включая псевдонимы, которые
  скрипт задаёт сам через `Set-Alias` / `New-Alias`, и их цепочки. Регистр и префикс модуля
  (`Microsoft.PowerShell.Management\Remove-Item`) не важны, сокращённые параметры (`-Rec`, `-fo`) понимаются.
- **Значения** отслеживаются, когда они постоянные: переменные (присваивание, действующее на этой строке), склейка
  строк, `-f`, `-join`, сплаттинг (`@params`) и раскрываемые строки.
- **Вложенный код** в `cmd /c`, `powershell -Command`, `Start-Process`, `Invoke-Command`, `Start-Job` и блоках скрипта
  тоже проверяется.
- **.NET и системные утилиты**: `[IO.File]::Delete`, `[IO.Directory]::Delete`, `FileSystem` из VisualBasic,
  `[Microsoft.Win32.Registry]`, `[Diagnostics.Process]::Start`, `Invoke-CimMethod` / WMI (`Win32_ShadowCopy`,
  `Win32Shutdown`), `vssadmin`, `wbadmin`, `bcdedit`, `diskpart`, `format`, `cipher /w`, `takeown` / `icacls` для
  системных путей, `reg delete`, `schtasks`, `sc delete`, `wevtutil cl`, `Set-MpPreference`, `netsh advfirewall … off`.

Пока PowerShell не ответил (секунду-две; результаты кэшируются), работает более простой встроенный сканер Shelly, а в
строке видно **проверяю**. Скрипт никогда не показывается как «ничего не найдено», пока его не проверил парсер
PowerShell. Если проверить его не может ни один PowerShell, в строке видно **не проверено**, и Shelly спросит перед
запуском. Перед запуском Shelly ждёт результат проверки до 30 секунд.

### Уровни

| Уровень | Отметка | Что происходит | Примеры |
|---|---|---|---|
| **Опасно** (красный) | красный щит | Вопрос перед **каждым** запуском. Пометить доверенным нельзя. | Удаление в системных папках, в корне диска, в профиле пользователя или в HKLM; форматирование, затирание и разметка дисков; `bcdedit`; выключение и перезагрузка; `reg delete` в HKLM; политика выполнения Unrestricted/Bypass насовсем; ослабление Defender; отключение брандмауэра; удаление служб, теневых и резервных копий, журналов событий; изменение учётных записей и группы «Администраторы»; права и владелец системных файлов; задания планировщика от SYSTEM или с наивысшими правами; **код, собранный на ходу** (см. ниже); **загрузка и запуск кода** |
| **Внимание** (жёлтый) | жёлтый щит | Вопрос перед запуском; можно «больше не предупреждать». | Удаление с `-Recurse` вне временных папок; рекурсивное удаление через .NET; `Start-Process -Verb RunAs`; запись в HKLM; задания планировщика; компиляция C# через `Add-Type` из текста в скрипте; отключение сетевого адаптера; политика выполнения только для сеанса |
| **Инфо** | нет | Показывается в окне, никогда не спрашивает. | `Remove-Item -Force` для конкретного элемента; удаление в `$env:TEMP` без `-Recurse`; вызов других локальных `.ps1`; строка base64, которая не выполняется; загрузки, которые не запускаются; код из **доверенного источника** |

### Код, собранный на ходу (динамический вызов)

Если скрипт собирает команду, которую выполняет, Shelly не может знать, что выполнится. Это **опасно** с сообщением
«Скрипт собирает команды на ходу; Shelly не может проверить, что он выполняет»:

- `& (…)`, `& $var`, `. $var` и имена вида `& ('Rem'+'ove-Item')` (постоянное имя раскрывается и проверяется как эта
  команда);
- `Invoke-Expression` / `iex`, `[scriptblock]::Create(…)`, `.Invoke()` / `.InvokeReturnAsIs()` у собранного блока,
  `$ExecutionContext.InvokeCommand…`, `Invoke-Command` / `Start-Job` с блоком из переменной;
- `-EncodedCommand` / `-enc` / `-e`, а также `[Convert]::FromBase64String`, если скрипт ещё и выполняет код;
- `Add-Type` с кодом из переменной или файла, рефлексия (`Assembly.Load`, `GetMethod(…).Invoke`, `InvokeMember`,
  `Marshal.GetDelegateForFunctionPointer`).

Блок, который скрипт пишет сам (`$sb = { … }; & $sb`), и параметр `[scriptblock]` его собственной функции проверяются
как обычный код и не отмечаются.

### Загрузка и запуск кода

Однострочники, которые скачивают код и выполняют его, — **опасно** с сообщением
«Скачивает и выполняет код из интернета: <url>» и найденным адресом. Распознаются `irm` / `iwr` /
`Invoke-RestMethod` / `Invoke-WebRequest` / `curl` / `wget` / `Net.WebClient.DownloadString` / `DownloadFile` /
`Start-BitsTransfer`, переданные через конвейер или аргументом в `iex`, `&`, `[scriptblock]::Create`, через переменную
(`$s = irm …; iex $s`), а также скачивание `.ps1` / `.exe` / `.msi` / `.bat` с последующим запуском через `&` или
`Start-Process`. Примеры:

```powershell
irm https://christitus.com/win | iex
iex (irm https://example.org/x.ps1)
iex(New-Object Net.WebClient).DownloadString('https://example.org/x.ps1')
& ([scriptblock]::Create((irm https://example.org/x.ps1)))
```

### Доверенные источники

**Параметры → Безопасность → Доверенные источники** — источники, код из которых отмечается как **инфо**
(«Выполняет код из доверенного источника X», с адресом), а не как опасность, и не вызывает вопроса. **Доверять
источнику — значит доверять всему, что он отдаст в момент запуска**: этот код Shelly не видит.

- Подходят только адреса **HTTPS**. Обычный `http://` и `irm example.com/x` без схемы (PowerShell скачает по http) не
  доверяются никогда.
- Хост подходит сам и со всеми поддоменами (`christitus.com` покрывает `www.christitus.com`, но не
  `christitus.com.evil.example`).
- На общих хостах (`github.com`, `raw.githubusercontent.com`, gist, `aka.ms`, сокращатели ссылок, файловые хостинги и
  pastebin, CDN, облачные хранилища) принимается только **хост + путь**: `raw.githubusercontent.com/owner/repo/`, но
  никогда весь хост. IP-адреса не принимаются.
- Окно **Проверка безопасности** предлагает **Доверять источнику (хост)** для каждого найденного адреса HTTPS. Кнопка
  добавляет источник и проверяет скрипт заново.

В Shelly есть **встроенный** список (с пометкой *встроенный*; каждый можно выключить, но не удалить). Каждая запись —
команда установки из документации самого проекта:

| Источник | Для | Документация |
|---|---|---|
| `christitus.com` | Chris Titus Tech WinUtil | https://github.com/ChrisTitusTech/winutil#quick-start |
| `get.scoop.sh` | Scoop | https://github.com/ScoopInstaller/Install#typical-installation |
| `community.chocolatey.org/install.ps1` | Chocolatey | https://chocolatey.org/install |
| `aka.ms/install-powershell.ps1` | PowerShell (Microsoft) | https://github.com/PowerShell/PowerShell/blob/master/tools/install-powershell.ps1-README.md |
| `raw.githubusercontent.com/PowerShell/PowerShell/` | репозиторий PowerShell (Microsoft) | то же |
| `dot.net/v1/dotnet-install.ps1` | скрипт установки .NET (Microsoft) | https://learn.microsoft.com/dotnet/core/tools/dotnet-install-script |
| `astral.sh` | uv (Astral) | https://docs.astral.sh/uv/getting-started/installation/ |
| `deno.land/install.ps1` | Deno | https://docs.deno.com/runtime/getting_started/installation/ |
| `bun.sh`, `bun.com` | Bun | https://bun.sh/docs/installation |
| `get.pnpm.io` | pnpm | https://pnpm.io/installation |
| `ohmyposh.dev` | Oh My Posh | https://ohmyposh.dev/docs/installation/windows |

Инструменты активации и пиратские инструменты намеренно не включены. Пример `Examples\Chris Titus WinUtil.ps1`
выполняет `irm https://christitus.com/win | iex` от администратора (`# Shelly-Mode: admin`): будет инфо-пометка,
подтверждение запуска от администратора и запрос UAC, а WinUtil откроется в своём окне.

### Скачан из интернета (Mark of the Web)

Браузеры, почта и мессенджеры помечают скачанные файлы потоком NTFS `Zone.Identifier`. Shelly его читает:

- Зона **Интернет** или **Ограниченные узлы** (ZoneId 3 или 4): в строке оранжевая **стрелка загрузки**, в подсказке —
  адрес загрузки и страница. Скрипт **не запускается** ниоткуда (список, трей, горячая клавиша, список переходов,
  история, омнибокс) и **не собирается** в .exe. При запуске открывается окно **Скачан из интернета** с адресами и
  результатом проверки. **Разблокировать** снимает пометку (как «Разблокировать» в свойствах файла); затем запустите
  скрипт снова — он пройдёт обычную проверку.
- То же касается локальных скриптов и модулей, которые скрипт загружает по постоянному пути (`. .\lib.ps1`,
  `. "$PSScriptRoot\lib.ps1"`, `& .\x.ps1`, `Import-Module .\m.psm1`); пути, собранные на ходу, не отслеживаются.
- Зона **Местная интрасеть** или **Надёжные узлы** (ZoneId 1 или 2): только примечание в подсказке.
- Shelly никогда не снимает пометку сам. Сохранение в редакторе Shelly, переименование и перемещение её сохраняют.
- Пометка есть только на NTFS. У файлов на FAT32/exFAT, на некоторых сетевых папках, у файлов из архиваторов, которые
  не переносят пометку, и у файлов, созданных скриптами, её нет. Эта часть проверена на имитации потока; проверьте её на
  своём компьютере с Windows (например, скачайте `.ps1` браузером).

### Подтверждение

Окно **Проверка безопасности** показывает каждую находку с уровнем, строкой и кодом. **Открыть в редакторе** открывает
скрипт вместо запуска.

- **Опасно**: отметьте **Я понимаю, что делает этот скрипт**; кнопка **Запустить** станет доступна через 3 секунды. Так
  при каждом запуске: скрипты с опасными находками нельзя пометить доверенными.
- **Внимание**: **Больше не предупреждать для этой версии скрипта** запоминает путь и SHA-256 файла; после любого
  изменения предупреждение вернётся. Список — в **Параметры → Безопасность → Доверенные скрипты**.
- Запуск **от администратора** всегда требует подтверждения, даже если ничего не найдено.
- **Не проверено** (ни один PowerShell не смог проверить скрипт): Shelly спросит перед запуском и покажет находки
  встроенного сканера.

**Отключение предупреждений.** Параметры → Безопасность → **Предупреждать перед запуском опасных скриптов** или `>` в
омнибоксе (с подтверждением). Без предупреждений пропускаются замечания «Внимание» и вопрос перед запуском от
администратора; **опасные находки и скачанные скрипты по-прежнему проверяются при каждом запуске**. Отметки в списке
остаются.

### Ограничения

Проверка не видит код, которого у неё нет: что отдаст адрес, файлы, которые скрипт читает или скачивает при запуске,
другие скрипты, вызванные через переменные, запускаемые программы, зашифрованные или запутанные данные, которые не
удаётся свернуть. Такие приёмы отмечаются как динамический или удалённый код, но отличить хороший код от плохого
проверка не может. Бывают и ложные срабатывания. Если сомневаетесь, прочитайте скрипт или запустите его в виртуальной
машине или в Песочнице Windows.

## 7. Редактор

Редактор открывается по **Ctrl+E**, из контекстного меню или через **Новый скрипт** (он создаёт скрипт по шаблону и
открывает его). В редакторе (AvalonEdit) есть подсветка синтаксиса PowerShell.

| Клавиши | Действие |
|---|---|
| Ctrl+S | Сохранить |
| F5 | Сохранить и запустить (обычный режим) |
| Ctrl+F, F3 / Shift+F3 | Найти, следующее / предыдущее |
| Ctrl+G | Перейти к строке |
| Ctrl+Space | Автодополнение. Оно открывается и само: после `$`, после `-` следом за пробелом и после трёх букв команды или ключевого слова. |
| Ctrl+= / Ctrl+- | Размер шрифта (9–32) |

- Панель инструментов: сохранить, запустить, перенос строк, номера строк, размер шрифта и **внешний редактор**.
  Внешний редактор — PowerShell ISE, если он есть, иначе Блокнот (в списке — Ctrl+Shift+E).
- Файлы всегда сохраняются в **UTF-8 с BOM**. Для файла в другой кодировке редактор предупредит, что при сохранении
  она будет изменена.
- В строке состояния — позиция курсора, кодировка, признак несохранённых изменений, ошибки разбора и предупреждения.
  Щелчок переходит к первой проблеме.
- При закрытии редактора или Shelly с несохранёнными изменениями Shelly спросит, что с ними делать.

## 8. Команды омнибокса

Щёлкните поле поиска (Ctrl+K, а на странице «Скрипты» и Ctrl+F). Ввод фильтрует скрипты. ↓ переходит в список, Enter
запускает выбранный скрипт, Esc очищает поле. Введите `>`, чтобы увидеть команды; текст после `>` их фильтрует.
Выбирайте стрелками и Enter или щелчком.

| Команда | Действие |
|---|---|
| Новый скрипт | Спрашивает имя (`Папка\Имя` создаёт скрипт в папке) и открывает редактор |
| Новая папка | Создаёт подпапку в `Scripts` |
| Открыть папку скриптов | Открывает её в Проводнике |
| Папка build | Открывает `build` в Проводнике |
| Обновить список | Заново просматривает `Scripts` |
| Сменить язык (English / Русский) | Применяется сразу |
| Тема и цвета | Открывает «Параметры» |
| Предупреждения: выкл / вкл | Переключает предупреждения (выключение требует подтверждения) |
| Проверка совместимости | Открывает страницу «Совместимость» |
| История, Параметры | Открывают эти страницы |
| Установить PowerShell 7… | См. [раздел 12](#12-установка-powershell-7) |

## 10. Трей, горячая клавиша, автозапуск, уведомления, список переходов

- **Значок в трее.** Щелчок левой кнопкой открывает Shelly. Правой — меню: **Открыть Shelly**, **Избранное**
  (запускается в отдельном окне) и **Выход**. Во всплывающей подсказке значка видно, что сейчас работает.
- **Кнопка «Закрыть».** По умолчанию она прячет Shelly в трей. В первый раз уведомление подскажет, как открыть окно
  снова. Если выключить **Кнопка «Закрыть» прячет Shelly в трей**, кнопка будет закрывать программу. Если ещё идут
  обычные запуски, Shelly спросит перед выходом.
- **Горячая клавиша** открывает Shelly из любого места. По умолчанию это **Ctrl+Alt+L**. В Параметры → Общие щёлкните
  поле и нажмите сочетание с Ctrl, Alt или Win плюс буква, цифра, F1–F24 или пробел. **Выкл** отключает клавишу,
  кнопка сброса возвращает Ctrl+Alt+L. Если сочетание уже занято другой программой, остаётся прежняя клавиша.
- **Запускать вместе с Windows** записывает `"…\Shelly.exe" --minimized` в `HKCU\…\Run\Shelly`. Если запись указывает на
  другую папку Shelly, это будет видно в параметрах; выключите и снова включите переключатель, чтобы она указывала на
  эту папку. **Запускать свёрнутым в трей** прячет окно при каждом запуске.
- **Уведомления.** Если обычный запуск длился дольше заданной задержки (по умолчанию 20 секунд) и закончился (успешно или с ошибкой), пока Shelly не на
  переднем плане, в трее появится уведомление. Щелчок по нему показывает вывод. Уведомления выключаются в Параметры →
  Запуск, там же в пункте **Уведомлять через** выбирается задержка: 10, 20, 30 или 60 секунд. (Ключ `toastAfterSec`
  в `launcher-settings.json` принимает любое значение от 0 до 3600.)
- **Список переходов.** Щёлкните Shelly на панели задач правой кнопкой, чтобы запустить скрипт из избранного. Он
  запускается в запомненном режиме, а если Shelly не запущен, программа запустится. Список выключается в Параметры →
  Запуск.

## 11. Сборка в .exe

**Ctrl+B** или **Собрать .exe** в контекстном меню собирает из скрипта консольный `.exe` компилятором C# из .NET
Framework 4, ничего устанавливать не нужно.

- Результат: `build\<те же подпапки, что в Scripts>\<Имя>.exe`. Перед перезаписью Shelly спросит, а потом покажет
  файл в Проводнике.
- Скрипт, скачанный из интернета, сначала нужно разблокировать (см. [раздел 6](#6-проверка-безопасности)).
- Скрипт с опасными находками проходит полную проверку (флажок **Я понимаю**, 3 секунды ожидания, **Я проверил
  скрипт**).
- Если в скрипте есть замечание «Внимание» или «Опасно», пометка Mark of the Web или PowerShell не смог его
  проверить, второе окно просит **ввести имя скрипта или `BUILD`**. Флажка намеренно недостаточно: `.exe` выполняет
  скрипт без проверок Shelly, а сборка не делает скрипт доверенным. Не распространяйте `.exe`, собранные из
  непроверенных скриптов.
- Движок фиксируется при сборке: закреплённый за скриптом или тот, что выбрал «Авто». Если на другом компьютере
  этого движка нет, exe возьмёт другой и выведет об этом сообщение.
- Значок exe — своя картинка скрипта (PNG преобразуется), иначе `assets\shelly.ico`. Символ из `# Shelly-Icon` для exe
  не используется.
- При запуске exe кладёт временную копию скрипта рядом с собой (`.<Имя>-<pid>.ps1`, а если не получилось — в
  `%TEMP%`), поэтому `$PSScriptRoot` указывает на папку exe. Копия запускается с `-NoProfile -ExecutionPolicy Bypass`,
  все аргументы exe передаются скрипту (например, `Имя.exe -Count 5 -Loud`), а в конце копия удаляется.
- Журнал сборки пишется в `shelly.log`. Если сборка не удалась, Shelly покажет вывод компилятора.

## 12. Установка PowerShell 7

Shelly ищет PowerShell 7 в Program Files (стабильную и preview-версии), через App Paths и PATH, а также версию из
Microsoft Store — через её псевдоним выполнения в `%LOCALAPPDATA%\Microsoft\WindowsApps`.

Установить его можно через **Установить PowerShell 7…** (Параметры → Движки, страница «Совместимость»,
информационная полоса, команды `>` или окно, которое появляется, когда скрипту нужна семёрка):

- **Через winget**, если он есть: в отдельном окне выполняется `winget install --id Microsoft.PowerShell --source winget
  --accept-package-agreements --accept-source-agreements`.
- **Без winget**: **Скачать и запустить установщик** скачивает последний MSI (x64 или ARM64) из релизов PowerShell на
  GitHub и запускает его. **Открыть страницу загрузки** открывает страницу релиза в браузере.

Shelly сам заметит новую установку, перезапуск не нужен. **Проверить снова** в Параметры → Движки или на странице
«Совместимость» повторяет поиск.

## 13. Обновления

Если включено **Проверять обновления при запуске** (Параметры → Обновления; включено по умолчанию), Shelly примерно
через 4 секунды после старта спрашивает у GitHub Releases (`api.github.com/repos/grvelvet/shelly/releases/latest`)
последнюю версию — примерно раз в день (не чаще раза в 20 часов). Если есть новая версия, на информационной полосе и в карточке «О программе»
появится **Скачать**, кнопка открывает страницу релиза. Ничего не скачивается и не устанавливается само. **Проверить
сейчас** в Параметры → О программе проверяет сразу.

## 15. Решение проблем и вопросы

**«Выполнение сценариев отключено в этой системе» / политика выполнения.** Shelly запускает скрипты с
`-ExecutionPolicy Bypass`, поэтому локальная политика не мешает. Политику из **групповой политики** обойти нельзя: если
там Restricted или запрет неподписанных скриптов, Windows их заблокирует. Политика видна на странице «Совместимость».

**Скрипт не запускается: «Скачан из интернета».** Windows пометила файл как скачанный. Прочитайте его и нажмите
**Разблокировать** в окне, которое откроется при запуске (см. [раздел 6](#6-проверка-безопасности)).

**SmartScreen: «Система Windows защитила ваш компьютер» / неизвестный издатель.** `Shelly.exe` не подписан. Сверьте
SHA-256 zip-архива с `SHA256SUMS.txt` из релиза (`Get-FileHash .\shelly-1.0.11.zip`), затем нажмите
**Подробнее → Выполнить в любом случае**.

**Shelly не запускается: «нет .NET».** Установите .NET 10 Desktop Runtime (x64) или возьмите автономную сборку
(selfcontained). См. [раздел 1](#1-установка-и-требования).

**Не находится PowerShell 7 из Microsoft Store.** Shelly запускает версию из Store через псевдоним `pwsh.exe`.
Проверьте, что псевдоним включён (Параметры Windows → Приложения → Дополнительные параметры приложений → Псевдонимы
выполнения приложений), и нажмите **Проверить снова** в Параметры → Движки.

**Скрипт ждёт ввода и зависает, или `Read-Host` падает с ошибкой.** У обычного запуска нет консольного ввода.
Используйте **Запустить в отдельном окне** или запомните этот режим в параметрах запуска.

**Кракозябры вместо русского текста в Windows PowerShell 5.1.** Сохраните скрипт в UTF-8 с BOM, например откройте и
сохраните его в редакторе Shelly.

**Не тот движок.** Подсказка отметки движка объясняет, почему «Авто» его выбрал. Закрепите движок в параметрах запуска
или добавьте в скрипт `#Requires`.

**«Собрать .exe» недоступно.** Не найден компилятор C# из .NET Framework 4. См. страницу «Совместимость».

**Медленный запуск.** Запустите `Shelly.exe --perf` (или задайте `SHELLY_PERF=1`, или добавьте `"perfLog": true` в
`launcher-settings.json`) и посмотрите `%TEMP%\Shelly\perf.log`.

**Журнал.** `%TEMP%\Shelly\shelly.log` (ротация при 512 КБ). Ссылка на него есть в Параметры → О программе.

## 16. Конфиденциальность

В Shelly нет телеметрии, аналитики и учётных записей. В сеть он обращается только:

- для проверки обновлений: один запрос к `api.github.com`, если проверка включена или вы нажали **Проверить сейчас**;
- когда вы выбираете **Установить PowerShell 7**: winget или релизы PowerShell на GitHub (для MSI);
- когда вы щёлкаете ссылку (GitHub, страницы загрузки) — она открывается в браузере.

Скрипты, настройки, история и журналы остаются на вашем компьютере. Сами скрипты, конечно, могут делать всё, что
написано в их коде.
