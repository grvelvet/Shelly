# Руководство пользователя Shelly 1.5.0

[English version](USER_GUIDE.md) · [README](../README.md) · [CHANGELOG](../CHANGELOG.md)

Shelly — портативный лаунчер скриптов PowerShell, Python, Batch и собственных интерпретаторов для Windows 10/11. Он собирает скрипты из `Scripts` и подключённых папок, читает параметры и описания, проверяет безопасность перед запуском, перехватывает вывод, ведёт историю, запускает задачи по расписанию, предоставляет встроенный редактор с линтером и собирает `.ps1` в `.exe`.

## 1. Установка, требования и структура папок

**Требования**

- Windows 10 или 11 (x64). Полное оформление (скруглённые углы, Mica, цветной заголовок) доступно в Windows 11; в Windows 10 используется упрощённое оформление.
- Windows PowerShell 5.1 (встроен в Windows). PowerShell 7 и Python 3 необязательны и нужны только для соответствующих скриптов.
- Для **Сборки в .exe** используется системный компилятор C# из .NET Framework 4 (`%WINDIR%\Microsoft.NET\Framework64\v4.0.30319\csc.exe`).

**Две сборки**

| Файл | `Shelly.exe` | Что нужно |
|---|---|---|
| `shelly-<версия>.zip` (рекомендуется) | ≈ 2 МБ | [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0) (x64) или `winget install Microsoft.DotNet.DesktopRuntime.10` |
| `shelly-<версия>-selfcontained.zip` | ≈ 70 МБ | ничего (среда выполнения вшита в exe, старт чуть медленнее) |

**Установка и первый запуск.** Распакуйте архив в любую папку (например, `C:\Tools\Shelly`) и запустите `Shelly.exe`. При первом запуске Shelly показывает предупреждение об ответственности (скрипты работают с правами пользователя, Shelly — не песочница) и создаёт рабочие каталоги. В одной папке одновременно работает только один экземпляр Shelly; повторный запуск выводит окно на передний план и передаёт ему аргумент `--run`.

**Где что хранится**

| Данные | Путь |
|---|---|
| Скрипты по умолчанию | `<папка Shelly>\Scripts\` (подпапки становятся группами; файлы в корне — группа **Общие**) |
| Настройки | `<папка Shelly>\launcher-settings.json` |
| История и логи выводов | `<папка Shelly>\launcher-history\` (`history.json` и файлы `<id>.log`) |
| Собранные `.exe` | `<папка Shelly>\build\` (повторяет структуру подпапок `Scripts`) |
| Значки | `<папка Shelly>\assets\shelly.ico` и `<папка Shelly>\assets\script-icons\` |
| Журнал, кэш анализа, замеры | `%TEMP%\Shelly\` (`shelly.log`, `analysis-cache.json`, `perf.log`) |
| Автозапуск (если включён) | `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`, параметр `Shelly` |

В `Scripts` попадают поддерживаемые скрипты до 8 уровней вложенности. Файлы и папки, начинающиеся с `.` или `_` (для Python-модулей), скрытые элементы, `__pycache__`, `site-packages`, `node_modules`, виртуальные окружения (`pyvenv.cfg`) и ссылки на папки (junction / symlink) пропускаются. Список обновляется автоматически при изменениях на диске; **F5** обновляет вручную.

### Внешние папки со скриптами

Помимо `Scripts`, можно подключить до 20 внешних папок на диске: перетащите папку в окно Shelly или добавьте её в **Параметры → Папки и файлы → Дополнительные папки → Добавить папку…**.

- **Запуск на месте:** файлы не копируются, рабочая папка — папка самого скрипта. В списке каждая папка становится отдельной группой со значком ссылки (подсказка показывает полный путь).
- **Изоляция метаданных:** скрипты получают идентификатор `ext:<id>\путь`, поэтому их избранное, доверие, параметры и история не смешиваются с `Scripts`. При удалении папки из настроек файлы на диске не затрагиваются, но привязанные метаданные забываются.
- **Ограничения:** до 8 уровней вложенности, не более 1000 скриптов и 2000 подпапок; ссылки (junction/symlink) не раскрываются. Для внешних скриптов недоступны переименование, удаление и сборка в `.exe` (редактирование работает на месте). Нельзя подключить `Scripts` или пересекающуюся с уже добавленной папку.

### Импорт папки (скрипты со своими файлами)

Если скрипту нужны лежащие рядом конфиги, данные или модули, используйте **Импортировать папку…** (команды `>` или меню группы `Scripts`). Перетаскивание папки в окно подключает её как внешнюю, а перетаскивание отдельных файлов копирует их в `Scripts`.

1. Shelly сканирует папку в фоне. Если объём превышает **100 МБ** или **2000 файлов**, предлагается **Подключить как внешнюю папку** либо **Всё равно импортировать**.
2. В диалоге можно задать имя подпапки в `Scripts` и снять флажки со вспомогательных скриптов (они скопируются, но будут скрыты из списка через файл `.shelly.json`).
3. Копирование идёт атомарно через временную папку. Окружения Python (`.venv`, `venv`, `env` с `pyvenv.cfg`), `__pycache__`, `.git`, `node_modules` и симлинки не копируются.

Скрипты импортированной папки отмечаются значком папки и запускаются в своём каталоге. При удалении последнего видимого скрипта папки Shelly предлагает отправить всю импортированную папку в Корзину (если скриптов несколько — можно удалить только запись из списка через `.shelly.json`). Внутри таких скриптов стройте пути от файла скрипта: `$PSScriptRoot` (PowerShell) или `Path(__file__).parent` (Python). Перед запуском по SHA-256 проверяется только сам файл скрипта.

## 2. Главное окно: Скрипты, Избранное, История

Боковая панель переключает разделы: **Скрипты** (`Ctrl+1`), **Избранное** (`Ctrl+2`), **История** (`Ctrl+3`) и **Параметры** (`Ctrl+,`). `Ctrl+M` или кнопка `☰` сворачивает панель до значков.

### Страница «Скрипты»

- **Панель инструментов:** *Новый скрипт*, *Новая папка* | *Сортировка* (по имени, дате изменения, последнему запуску или числу запусков), *Свернуть / Развернуть все* (`Ctrl+Shift+[` / `]`), *Вид* (**Карточки** 64 px или **Компактный список** 40 px), *Фильтр* (уже запускались, ни разу не запускались, нужен PS 5.1, предупреждения безопасности, запуск от администратора, только избранное; фильтры действуют до закрытия Shelly), **омнибокс** (поиск по имени, папке и описанию + команды `>`), *Обновить* (`F5`) и *Открыть папку*. В узком окне кнопки автоматически прячутся в меню `…`.
- **Строка скрипта:**
  - Слева от названия отображается **звёздочка избранного** (если добавлен).
  - В названии **сохраняется расширение файла** (`.ps1`, `.py`, `.bat`, `.cmd` или расширение своего интерпретатора). Рядом могут выводиться отметки **venv**, название своего интерпретатора, значок часов (расписание) и метка импортированной папки.
  - **Щит безопасности:** зелёный — скрипт доверен (для текущего SHA-256), жёлтый — есть предупреждения, красный — опасные находки или пометка Mark of the Web (оранжевая стрелка загрузки); часы — идёт проверка AST, `?` — скрипт не удалось проверить. У чистых скриптов или при сбросе доверия щит не показывается.
  - **Результат запуска:** отметка появляется только при ошибке (с кодом выхода) или остановке пользователем; при наведении доступны кнопки ▶ *Запустить* и ⚙ *Параметры запуска* (во время работы — индикатор, таймер и ⏹ *Остановить*).
- **Контекстное меню строки:** *Остановить*, *Запустить*, *Запустить со встроенным выводом / в отдельном окне*, *Запустить от администратора*, *Запустить с пресетом*, *Параметры запуска…*, *Расписание…*, *Изменить*, *Открыть во внешнем редакторе*, *Собрать .exe*, *В избранное / Убрать из избранного*, *Убрать из доверенных* (для доверенных скриптов), *Сменить значок… / Значок по умолчанию*, *Показать запуски*, *Переименовать*, *Открыть расположение*, *Копировать путь*, *Удалить* (в Корзину).

### Панель вывода, «Избранное» и «История»

- **Панель вывода (снизу):** поток вывода выбранного запуска в реальном времени (до 4 МБ или 100 000 строк; остальное отмечается как пропущенное). Кнопки: *Остановить*, *Запустить снова*, *Открыть скрипт*, *Копировать*, *Сохранить в `.txt`*, *Очистить вид*, *Перенос строк*, *Найти* (`Ctrl+F`).
- **Избранное (`Ctrl+2`):** плитки избранных скриптов. Сортировка: *Вручную* (порядок можно менять в контекстном меню; этот же порядок используется в трее и Jump List), *По имени*, *По последнему запуску*, *По частоте* и *По типу* (PowerShell → Python → Batch → свои). Размер плиток: *Мелкие*, *Средние*, *Крупные* или `Ctrl + колесо мыши`.
- **История (`Ctrl+3`):** фиксирует все запуски (встроенные, в отдельном окне, от администратора, из трея, редактора и по расписанию) с результатом, кодом выхода, длительностью, движком, режимом, пресетом, параметрами и **полным сохранённым выводом** (в том числе для запусков в отдельном окне). Фильтр по статусу и поиск; `Enter` повторяет запуск с теми же параметрами, `Del` удаляет запись.

## 3. Запуск скриптов, параметры, пресеты и расписание

### Режимы запуска

| Режим (`# Shelly-Mode:`) | Поведение |
|---|---|
| **Отдельное окно** (`window`, по умолчанию) | Открывает консоль (`-NoExit`, окно остаётся открытым), но захватывает консольный вывод через транскрипт в панель вывода и в «Историю» в реальном времени. Интерактивный ввод (`Read-Host`, `input()`, `pause`) работает штатно. |
| **Встроенный вывод** (`inline`) | Запускает скрыто с `-NonInteractive` и перенаправленным выводом в панель Shelly. Ввода с клавиатуры нет. |
| **От администратора** (`admin`) | Повышение прав через UAC с обязательным подтверждением и повторной проверкой SHA-256 после UAC. |
| **GUI-режим** (`gui`) | Запуск графических скриптов без мелькания консольного окна. |
| **Скрытый режим** (`hidden`) | Тихий фоновый запуск без окна консоли и без мелькания на панели задач. |

Приоритет выбора режима при нажатии ▶ / `Enter` / двойном щелчке: запомненный режим для скрипта → директива `# Shelly-Mode:` → **Параметры → Запуск → Режим запуска по умолчанию**. Пункты контекстного меню используют выбранный режим явно; избранное из трея всегда открывается в окне; `F5` в редакторе всегда запускает со встроенным выводом.

Несколько разных скриптов могут работать параллельно; один и тот же скрипт во встроенном режиме запускается не более чем в одном экземпляре. Кнопка ⏹ *Остановить* завершает всё дерево дочерних процессов.

### Параметры запуска и пресеты

Диалог **Параметры запуска** (`Ctrl+I` или `Ctrl+Enter`) показывает:
- для PowerShell — форму, автоматически построенную из `param()` (обязательные поля с `*`, типы, флажки, выпадающие списки `ValidateSet`); для Python, Batch и своих интерпретаторов — одно поле **Аргументы**;
- выбор движка PowerShell (`Авто / 5.1 / 7`) и режима запуска;
- флажок **Запомнить для скрипта** (сохраняет значения и режим для обычного запуска).

**Пресеты параметров** — именованные наборы значений (кнопка *Сохранить как…* в параметрах запуска). Пресет можно запустить из контекстного меню (**Запустить с пресетом**) или привязать к расписанию. Если в обновлённом скрипте параметр пропал, Shelly предупредит об этом и пропустит лишнее значение. **Пресеты хранятся открытым текстом в `launcher-settings.json` — не сохраняйте в них пароли и токены.**

### Запуск по расписанию

Пункт **Расписание…** в контекстном меню создаёт задачу в Планировщике заданий Windows (`\Shelly\`) с правами текущего пользователя (без прав администратора). Поддерживаются графики: *Один раз*, *Ежедневно*, *По дням недели*, *При входе в Windows* (+30 с) и *Каждые N минут* (1–1440), с пресетом и выбором режима (*Скрыто* или *В отдельном окне*). Скрипты, требующие прав администратора, в расписание ставить нельзя.

Задача вызывает `Shelly.exe --scheduled <id>`. Если Shelly уже открыт — запуск идёт через него, иначе фоновый процесс выполняет скрипт, записывает итог в историю и показывает уведомление. Расписание работает без диалогов: любая проверка, требующая ответа пользователя (неподтверждённые предупреждения или опасные находки, Mark of the Web, пропавший пресет, пустой обязательный параметр), **пропускает запуск** (код выхода `-1` с причиной в истории). Просмотр, запуск вручную (*Запустить сейчас*) и восстановление задач после переноса папки Shelly находятся в **Параметры → Расписание**.

### Командная строка

| Аргумент | Действие |
|---|---|
| `--run "Папка\Скрипт.ps1"` (также `-run`, `/run`) | Запускает скрипт по относительному пути в `Scripts` (для внешней папки: `ext:<id>\Скрипт.ps1`) |
| `--preset "<имя>"` | Используется вместе с `--run` для запуска с указанным пресетом |
| `--headless` | Вместе с `--run`: тихий запуск без диалогов (как по расписанию) |
| `--scheduled <id>` | Внутренний вызов задачи Планировщика по id расписания |
| `--history <id запуска>` | Открывает Shelly на указанной записи в «Истории» |
| `--minimized` (также `-minimized`, `/minimized`, `--tray`) | Запуск свёрнутым в системный трей |
| `--perf` | Запись замеров старта в `%TEMP%\Shelly\perf.log` |

## 4. Языки и среды выполнения

- **PowerShell (`.ps1`):** в режиме **Авто** Shelly анализирует `#Requires` (`-Version`, `-PSEdition`) и синтаксис скрипта (операторы PS 7 вроде `??`, `&&`, `? :`, `ForEach-Object -Parallel` или команды только 5.1 вроде `workflow`), затем при необходимости берёт значение из **Параметры → Окружение → Версия PowerShell** (*Системная*, *5.1* или *7+*). Все запуски идут с `-NoProfile -ExecutionPolicy Bypass`. Установить PowerShell 7 можно командой `>` *Установить PowerShell 7…* (через `winget` или официальный MSI с GitHub с проверкой подписи и SHA-256).
- **Python (`.py`):** настраивается в **Параметры → Окружение → Python**. Порядок выбора интерпретатора: ближайшее виртуальное окружение (`.venv`, `venv` или `env` с `pyvenv.cfg` от папки скрипта вверх до корня `Scripts` или внешней папки, если включено *Использовать .venv рядом со скриптом*) → указанный вручную `python.exe` → автопоиск (`py -3`, `PATH` без пустой заглушки Store, `%LOCALAPPDATA%\Programs\Python`, `Program Files`). Скрипты запускаются как `python -u script.py` с `PYTHONUTF8=1`, `PYTHONIOENCODING=utf-8` и настроенными `VIRTUAL_ENV`/`PATH`. Если найденная папка `.venv` повреждена (нет `python.exe`), Shelly останавливает запуск с ошибкой и не подменяет окружение системным Python.
- **Batch (`.bat`, `.cmd`):** работает из коробки через `%ComSpec% /d /s /c "call …"` без настройки. Скрипты в UTF-8 без BOM автоматически получают `chcp 65001`; вывод во встроенной панели декодируется построчно (UTF-8 или OEM cp866). Символы `"`, `%`, `^` в поле *Аргументы* запрещены. Встроенный вывод не поддерживает ввод с клавиатуры (`pause`, `set /p`) — такие скрипты запускайте в отдельном окне. Файлы `.bat` в UTF-8 с BOM вызывают предупреждение (т.к. `cmd.exe` не выполнит первую строку).
- **Свои интерпретаторы:** в **Параметры → Окружение → Свои интерпретаторы** можно привязать любые расширения (кроме встроенных `.ps1`, `.py`, `.bat`, `.cmd` и исполняемых) к любой программе, задав шаблон аргументов (`{script} {args}`, `{dir}`) и рабочую папку. Все аргументы экранируются по правилам `CommandLineToArgvW`.

### Матрица возможностей по языкам

| Возможность | PowerShell | Python | Batch | Свой интерпретатор |
|---|:-:|:-:|:-:|:-:|
| Форма параметров (`param()`) | да | нет | нет | нет |
| Поле «Аргументы» | нет | да | да | да |
| Именованные пресеты | да | да | да | да |
| Проверка безопасности при запуске | полная (AST) | нет | упрощённая | нет |
| Живой линтер в редакторе (`F8`) | да (AST + правила) | да (правила + `ast.parse`) | да (правила + скан) | базовый |
| Подсветка синтаксиса (светлая / тёмная) | да | да | да | по расширению |
| Автодополнение (`Ctrl+Space`) | да | да | да | нет |
| Блок Mark of the Web, UAC, расписание | да | да | да | да |
| Захват вывода в окне и «История» | да | да | да | да |
| Автопоиск и виртуальные окружения | PS 5.1 / 7 | Python + `.venv` | `cmd.exe` | нет |
| Сборка в `.exe` | да | нет | нет | нет |

**Чего Shelly не делает:** не изолирует скрипты (не песочница); не передаёт клавиатурный ввод во встроенный режим вывода; не запускает задания планировщика от администратора; не собирает `.exe` из Python, Batch и своих скриптов; не синхронизирует настройки в облако.

## 5. Как писать скрипты для Shelly

- **Описание в списке:** берётся из первого `#`-комментария в первых 8 строках (префиксы `Описание:` / `Description:` убираются; `#Requires`, `#!` и `# Shelly-…` пропускаются) или из первого абзаца `.SYNOPSIS` блока `<# … #>` (в первых 60 строках).
- **Директивы в шапке комментариев:**
  - `# Shelly-Icon: E9D2` (в первых 40 строках; форматы `E9D2`, `U+E9D2`, `0xE9D2`, `\uE9D2`) — значок из шрифта Segoe Fluent Icons (собственная иконка `.ico`/`.png` через *Сменить значок…* имеет приоритет).
  - `# Shelly-Mode: window | inline | admin | gui | hidden` — режим запуска по умолчанию.
- **Кодировка:** для `.ps1` используйте **UTF-8 с BOM** (иначе PowerShell 5.1 исказит кириллицу); для `.py`, `.bat`, `.cmd` и других скриптов — **UTF-8 без BOM**. Редактор Shelly сохраняет файлы именно так.
- **Параметры PowerShell (`param()`):**

| Объявление в `.ps1` | Элемент в форме | Передача |
|---|---|---|
| `[string]$Name`, `[datetime]$When` | текстовое поле | `-Name 'значение'` |
| `[int]$Count = 3` (числовые типы) | поле с подсказкой `3` | `-Count '5'` |
| `[switch]$Loud`, `[bool]$Flag` | флажок | `-Loud` / `-Loud:$false`, `-Flag:$true` |
| `[string[]]$Items` | строка через запятую | `-Items 'a','b'` |
| `[ValidateSet('A','B')]` | выпадающий список | `-Param 'A'` |
| `[Parameter(Mandatory, HelpMessage='…')]` | обязательное `*` + подсказка | — |

**Пример `.ps1`:**

```powershell
# Описание: Копирует файлы выбранного расширения.
# Shelly-Icon: E8C8
#Requires -Version 5.1

param(
    [Parameter(Mandatory = $true, HelpMessage = 'Откуда копировать')]
    [string]$Source,

    [Parameter(Mandatory = $true, HelpMessage = 'Куда копировать')]
    [string]$Destination,

    [ValidateSet('txt', 'log', 'csv')]
    [string]$Extension = 'txt',

    [switch]$WhatIf
)

$files = Get-ChildItem -LiteralPath $Source -Filter "*.$Extension" -File
if (-not $files) { Write-Host "Файлов не найдено"; exit 1 }
New-Item -ItemType Directory -Path $Destination -Force | Out-Null
foreach ($f in $files) {
    if ($WhatIf) { Write-Host "Будет скопирован $($f.Name)" }
    else { Copy-Item -LiteralPath $f.FullName -Destination $Destination }
}
```

## 6. Проверка безопасности

> **Ограждение, а не песочница.** Скрипт всегда выполняется с правами вашей учётной записи Windows (при запуске от администратора — с полным контролем). Статический анализ помогает заметить опасные конструкции, но не гарантирует безопасность. Запускайте только те скрипты, которые понимаете и которым доверяете.

### Как работает проверка

Для `.ps1` Shelly использует собственный парсер PowerShell (AST) в PowerShell 7 или 5.1 (пока парсер отвечает — работает быстрый встроенный C#-сканер со статусом *проверяю*). Перед запуском Shelly ждёт результат до 60 секунд.

Анализатор отслеживает:
- **команды и псевдонимы:** полная таблица встроенных алиасов 5.1 и 7 (`rm`, `ri`, `del`, `iwr`, `irm`, `iex`, `curl`, `wget`…), локальные `Set-Alias` / `New-Alias` и их цепочки, имена с модулями и сокращённые флаги;
- **свёртку констант и вложенность:** постоянные переменные, склейку строк, `-f`, `-join`, сплаттинг `@params`, а также вложенный код в `cmd /c`, `powershell -Command`, `Start-Process`, `Invoke-Command`, `Start-Job` (вложенность глубже 3 уровней отмечается предупреждением);
- **.NET, WMI и системные утилиты:** `[IO.File]::Delete`, `[Microsoft.Win32.Registry]`, `Process.Start`, `Win32_ShadowCopy`, `Win32Shutdown`, `vssadmin`, `wbadmin`, `bcdedit`, `diskpart`, `format`, `cipher /w`, `takeown`/`icacls`, `reg delete`, `schtasks`, `sc delete`, `wevtutil cl`, `Set-MpPreference`, `netsh advfirewall`, `mshta`/`regsvr32`/`msiexec`/`certutil`, ключи автозагрузки `Run`.

Для `.bat`/`.cmd` применяется упрощённый сканер опасных команд (без раскрытия `%VAR%`). Скрипты Python и своих интерпретаторов не проверяются.

### Уровни находок и подтверждение

| Уровень | Щит | Поведение | Примеры |
|---|---|---|---|
| **Опасно** | красный | Требует отметить *«Я понимаю…»* и выждать 3 с. Запоминается по **пути + SHA-256** файла; при любом изменении файла спрашивает заново. | Удаление системных папок, корня диска, профиля, HKLM; форматирование, `bcdedit`, отключение Defender/брандмауэра; удаление теневых копий/служб/журналов; **динамический вызов** (`iex`, `& $var`, `-enc`, `FromBase64String` + запуск, рефлексия, `Add-Type` из переменной); **загрузка и запуск из сети**. |
| **Внимание** | жёлтый | Спрашивает перед запуском. Можно отметить *«Больше не предупреждать для этой версии»* (присваивает **зелёный щит** доверия текущему SHA-256). | `Remove-Item -Recurse` вне TEMP; `Start-Process -Verb RunAs`; запись в HKLM / автозагрузку; `Add-Type` из текста; задания планировщика; слишком глубокая вложенность или ошибка разбора. |
| **Инфо** | нет | Отображается в окне проверки, запуск не блокирует. | Удаление в `$env:TEMP` без `-Recurse`; запуск локальных `.ps1`; код из **доверенного источника**. |

Отозвать доверие (зелёный или подтверждённый красный щит) можно через контекстное меню строки → **Убрать из доверенных**. Запуск **от администратора** всегда запрашивает подтверждение. Отключение предупреждений в **Параметры → Безопасность** отключает только подсказки анализатора — **Mark of the Web и UAC проверяются всегда**.

### Доверенные источники и Mark of the Web

- **Доверенные источники** (**Параметры → Безопасность**): HTTPS-адреса, для которых загрузка и запуск (`irm … | iex`) понижаются до уровня *Инфо*. Обычный `http://` и IP-адреса не принимаются; для общих хостингов (`github.com`, `raw.githubusercontent.com`, `aka.ms`, CDN) указывается полный путь с владельцем и репозиторием. Встроенный список (WinUtil, Scoop, Chocolatey, PowerShell, .NET, uv, Deno, Bun, pnpm, Oh My Posh) можно отключать поштучно.
- **Mark of the Web (`Zone.Identifier`):** файлы из интернета или ограниченных узлов (ZoneId 3 или 4) на дисках NTFS помечаются оранжевой стрелкой и **блокируются от запуска и сборки в `.exe`** до нажатия **Разблокировать** (то же относится к локальным модулям, подключаемым по явному пути). Shelly никогда не снимает эту метку сам.

## 7. Редактор и встроенный линтер

Встроенный редактор (AvalonEdit) открывается по `Ctrl+E`, через *Изменить* или при создании *Нового скрипта*.

### Возможности и клавиши

- **Подсветка синтаксиса** для светлой и тёмной тем: PowerShell, Python, Batch и подсветка по расширению для других языков.
- **Автодополнение (`Ctrl+Space`):** работает для PowerShell, Python и Batch (также открывается автоматически при вводе команд, переменных `$` и параметров `-`).
- **Встроенный линтер в реальном времени:** подчёркивает проблемы красной или жёлтой волнистой линией (с подсказкой `[Код] Описание` при наведении) и выводит их список в выдвижной панели **Проблемы** (`F8` или щелчок по индикатору в строке состояния):
  - *PowerShell:* ошибки AST, предупреждения безопасности/совместимости, пустой `catch {}` (`PS-EMPTY-CATCH`), захардкоженные секреты (`PS-SECRET`), алиасы (`PS-ALIAS`), глобальный `$ErrorActionPreference = 'SilentlyContinue'` (`PS-ERRPREF`).
  - *Python:* смешивание табов и пробелов (`PY-TAB-SPACE`), голый `except:` (`PY-BARE-EXCEPT`), изменяемые аргументы по умолчанию (`PY-MUTABLE-DEFAULT`), `print` из Python 2 (`PY-PRINT2`), `== None` (`PY-EQ-NONE`), а также проверка синтаксиса через `ast.parse` (`PY-SYNTAX`).
  - *Batch:* предупреждение о UTF-8 с BOM (`BAT-BOM`), `!VAR!` без `EnableDelayedExpansion` (`BAT-DELAYED-EXP`), `goto` на несуществующую метку (`BAT-MISSING-LABEL`), одинарный `%i` в `for` (`BAT-FOR-PERCENT`), скобки (`BAT-PARENS`) и опасные команды.
  - *Свои скрипты:* проверка UTF-8 BOM (`CUSTOM-BOM`) и незакрытых кавычек (`CUSTOM-QUOTES`).
- **Кодировки при сохранении:** `.ps1` сохраняются в **UTF-8 с BOM**, все остальные скрипты — в **UTF-8 без BOM** (bat-файлы не в UTF-8 открываются в OEM cp866).

| Клавиши | Действие |
|---|---|
| `Ctrl+S` / `F5` | Сохранить / Сохранить и запустить (со встроенным выводом) |
| `F8` | Открыть или скрыть панель «Проблемы» |
| `Ctrl+Space` | Автодополнение |
| `Ctrl+F`, `F3` / `Shift+F3`, `Ctrl+G` | Найти, далее / назад, перейти к строке |
| `Ctrl+=` / `Ctrl+-` | Изменить размер шрифта (9–32) |

### Выбор внешнего редактора

Нажмите значок шестерёнки в редакторе или откройте **Параметры → Общие → Редактор скриптов**:
- задайте редактор по умолчанию для `Ctrl+E` (встроенный или внешний);
- выберите внешнюю программу: *Автоматически* (VS Code → Notepad++ → ISE для `.ps1` / IDLE для `.py` → Блокнот), *VS Code*, *Notepad++*, *PowerShell ISE* (только `.ps1`), *Блокнот* или *Своя программа…* с подстановками `{file}` и `{line}`.
- `Ctrl+Shift+E` в списке всегда открывает файл во внешнем редакторе с переходом на нужную строку.

## 9. Сборка в .exe

`Ctrl+B` или **Собрать .exe** (только для `.ps1`) компилирует консольный `.exe` в `build\<подпапки>\<Имя>.exe` с помощью системного `csc.exe`.

- **Безопасность:** файлы с Mark of the Web нужно сначала разблокировать; если есть любые предупреждения, опасные находки или скрипт не проверен PowerShell, после проверки безопасности нужно подтвердить сборку вводом имени скрипта или слова `BUILD`. **Не распространяйте `.exe` из непроверенных скриптов: собранный файл запускается без проверок Shelly.**
- **Движок и значок:** в `.exe` зашивается выбранный для скрипта движок (или результат «Авто»); если на целевом ПК его нет, используется доступный PowerShell. Значок берётся из картинки скрипта (`.ico`/`.png`), иначе `assets\shelly.ico` (глиф `# Shelly-Icon` в `.exe` не используется).
- **Выполнение:** при запуске `.exe` распаковывает временную копию скрипта со случайным суффиксом рядом с собой (или в `%TEMP%`, если нет прав записи) — поэтому `$PSScriptRoot` указывает на папку `.exe`, передаёт все аргументы командной строки и удаляет копию после завершения.

## 10. Справочник параметров, обновления и вопросы

### Параметры (`launcher-settings.json`)

Перед ручной правкой `launcher-settings.json` закройте Shelly. Незнакомые ключи при сохранении не удаляются.

| Раздел | Основные параметры | По умолчанию |
|---|---|---|
| **Общие** | Язык (`English` / `Русский`), Автозапуск, Свёрнутым в трей, Кнопка «Закрыть» прячет в трей, Глобальная клавиша, Редактор скриптов | `English`, трей вкл, `Ctrl+Alt+L`, встроенный |
| **Оформление** | Тема (`Как в системе` / `Светлая` / `Тёмная`), Цвет акцента (Windows или 9 цветов) | Как в системе, акцент Windows |
| **Запуск** | Режим по умолчанию (`В отдельном окне` / `Встроенный вывод`), Уведомления, Порог длительности, Избранное в Jump List | Отдельное окно, Всегда, 20 с, вкл |
| **Расписание** | Список задач: вкл/выкл, Запустить сейчас, Изменить, Удалить, Восстановить, очистка лишних задач | нет |
| **Окружение** | Среда выполнения (`PowerShell` / `Python` / `Свои интерпретаторы`), Версия PS (`Системная` / `5.1` / `7+`), путь к `python.exe` и `.venv`, список своих интерпретаторов (до 20) | PS Системная, Python автопоиск + `.venv` вкл |
| **Безопасность** | Предупреждать перед опасными скриптами, Доверенные источники (встроенные вкл/выкл и свои) | вкл |
| **История** | Хранить запусков (`50` / `100` / `200`), Сохранять вывода на запуск (`256 КБ` / `1 МБ` / `5 МБ` / `20 МБ`) | 100, 1 МБ |
| **Папки и файлы** | Папка по умолчанию (`Scripts`), Дополнительные папки (до 20 внешних), Папка `build`, `launcher-settings.json` | не добавлены |
| **Обновления** | Проверять обновления при запуске (запрос к GitHub Releases не чаще раза в 20 ч; ничего не качается само) | вкл |
| **О программе** | Версия и ссылка на репозиторий GitHub | — |

### Частые вопросы и диагностика

- **«Выполнение сценариев отключено в этой системе»:** локальную политику Shelly обходит через `-ExecutionPolicy Bypass`, но запрет из **групповой политики (GPO)** обойти нельзя.
- **SmartScreen: «Неизвестный издатель»:** `Shelly.exe` не имеет цифровой подписи. Сверьте SHA-256 архива с `SHA256SUMS.txt` (`Get-FileHash .\shelly-1.5.0.zip`), затем нажмите *Подробнее → Выполнить в любом случае*.
- **Не запускается малая сборка («нет .NET»):** установите [.NET 10 Desktop Runtime (x64)](https://dotnet.microsoft.com/download/dotnet/10.0) или скачайте сборку `-selfcontained.zip`.
- **Не находится PowerShell 7 из Microsoft Store:** включите псевдоним `pwsh.exe` в *Параметры Windows → Приложения → Дополнительные параметры приложений → Псевдонимы выполнения приложений*.
- **Скрипт с `Read-Host` / `input()` / `pause` падает или сразу проходит:** запустите его в режиме **Отдельное окно** вместо встроенного вывода.
- **Кракозябры в PowerShell 5.1:** откройте скрипт во встроенном редакторе и пересохраните (он запишет `.ps1` в UTF-8 с BOM).
- **Медленный старт и логи:** запустите `Shelly.exe --perf` (результат в `%TEMP%\Shelly\perf.log`). Ошибки работы и неудачных запусков пишутся в `%TEMP%\Shelly\shelly.log` (ротация при 512 КБ).

### Конфиденциальность

Shelly не собирает телеметрию и не требует учётных записей. В сеть программа обращается только при проверке обновлений (`api.github.com`), при установке PowerShell 7 по вашей команде или при переходе по ссылкам в браузер. Все скрипты, настройки, история и журналы остаются на вашем ПК.
