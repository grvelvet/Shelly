# Screenshots

Put screenshots of Shelly here. The main README shows `docs/logo.png` (the app icon, rendered from `assets/shelly.svg`) and `docs/screenshot.png`.

Tips:
- Take the screenshot with Win+Shift+S, save it as PNG and name it `screenshot.png`.
- About 1200-1600 px wide looks good on GitHub.
- More images (for example `editor.png`, `dark.png`) can be added and linked from README.md.
- Check that no personal names, paths or private scripts are visible.
