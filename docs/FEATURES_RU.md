# Shelly 1.4.1: что умеет

Коротко: одна строка на возможность, «что делает → где в интерфейсе». Подробности в [руководстве](USER_GUIDE_RU.md).

## Скрипты и папки
- Список всех `.ps1`, `.py`, `.bat`, `.cmd` и расширений своих интерпретаторов с группами по папкам → «Скрипты» (Ctrl+1).
- Поиск по имени, папке, описанию и команды `>` → омнибокс (Ctrl+K / Ctrl+F).
- Сортировка, вид «Карточки / Компактный», фильтры, свернуть всё → кнопки слева от омнибокса.
- Новый скрипт по расширению имени (`.ps1`, `.py`, `.bat`, `.cmd`), новая папка → Ctrl+N / Ctrl+Shift+N.
- Внешние папки, скрипты запускаются на месте → Параметры → Папки и файлы или перетаскивание папки в окно Shelly.
- Импорт папки со своими файлами (без venv, `.git`, `node_modules`) → `>` Импорт папки…
- Свой значок, переименование, удаление в Корзину, «Открыть расположение» → контекстное меню строки.

## Запуск и режимы
- Запуск в отдельном окне (по умолчанию) или со встроенным выводом → Параметры → Запуск; разово: меню строки.
- Захват консольного вывода даже при запуске в отдельном окне (в реальном времени и в историю) → панель вывода и «История».
- Запуск от администратора с повторной сверкой SHA-256 после UAC → меню строки.
- Остановка всего дерева процессов → ⏹ в строке или в панели вывода.
- Блок файлов «скачан из интернета» до разблокировки → окно при запуске.

## Языки: PowerShell / Python / Batch / свои
- PowerShell 5.1 и 7, «Авто» по `#Requires`, движок можно закрепить → Параметры запуска; Параметры → Окружение.
- Python 3: автопоиск, свой `python.exe`, `.venv` рядом со скриптом, метки **PY**/**venv** → Параметры → Окружение → Python.
- Batch (`.bat`, `.cmd`) встроен, без настройки: `cmd.exe /d /s /c`, код из `errorlevel`, метка **BAT**/**CMD**.
- Кириллица в bat: UTF-8 файл получает `chcp 65001`, вывод построчно UTF-8 или OEM (cp866) → панель вывода.
- Свои интерпретаторы: расширения → программа, шаблон `{script} {args} {dir}`, метка = название → Параметры → Окружение → Свои интерпретаторы.

## Параметры и пресеты
- Форма из `param()` PowerShell (типы, обязательные, ValidateSet) → Параметры запуска (Ctrl+I).
- Одно поле «Аргументы» для Python, Batch и своих → там же.
- Пресеты: именованные наборы значений, «Запомнить для скрипта» → там же; меню строки и избранного.

## Избранное
- Звёздочка → Ctrl+D или меню; плитки → «Избранное» (Ctrl+2).
- Сортировка: вручную, по имени, по последнему запуску, по частоте, по типу (PS, Python, Batch, свои) → кнопка «Сортировка».
- Размер плиток → кнопка «Размер» или Ctrl+колесо.

## История и вывод
- Все запуски с результатом, кодом, длительностью, движком, аргументами и полным выводом (включая оконные запуски) → «История» (Ctrl+3).
- Повтор с теми же параметрами → Enter в истории; «Показать запуски» в меню строки.
- Вывод в реальном времени, копировать, сохранить `.txt`, поиск → панель вывода снизу.

## Расписание и уведомления
- Расписание через Планировщик Windows (однократно, ежедневно, по дням, при входе, каждые N минут) → меню строки → Расписание.
- Работает и при закрытом Shelly, без прав администратора; список и «Запустить сейчас» → Параметры → Расписание.
- Уведомление о конце запуска (выкл / ошибки / всегда, порог длительности) → Параметры → Запуск.

## Безопасность
- Проверка PowerShell по AST (псевдонимы, splatting, динамический вызов, загрузка и запуск) → метка-щит, окно при запуске.
- Упрощённая проверка bat-файлов: известные опасные команды, те же уровни → метка-щит.
- Доверенные версии скриптов помечаются бейджем **ДОВЕРЕН** прямо в списке главного окна (отозвать доверие: контекстное меню строки → «Убрать из доверенных»).
- Доверенные источники → Параметры → Безопасность.

## Редактор и встроенный линтер
- Встроенный редактор с подсветкой для светлой и тёмной темы (PowerShell, Python, Batch, свои скрипты), автодополнением (`Ctrl+Space`) для PowerShell, Python и Batch, F5 = сохранить и запустить → Ctrl+E.
- Встроенный линтер в реальном времени (волнистые подчёркивания с подсказками при наведении и выдвижная панель «Проблемы» по щелчку в строке состояния или `F8`) для PowerShell, Python, Batch и своих скриптов.
- Выбор редактора по умолчанию (встроенный или внешний) и программы внешнего редактора (Авто, VS Code, Notepad++, PowerShell ISE, Блокнот, своя программа с `{file}` и `{line}`) → кнопка шестерёнки в редакторе или Параметры → Общие → Редактор скриптов.
- `.ps1` в UTF-8 с BOM, остальные без BOM; bat не в UTF-8 читается как OEM → строка состояния.
- Открыть во внешнем редакторе с переходом на строку → Ctrl+Shift+E.

## Трей, горячие клавиши, jump list, CLI
- Значок в трее с избранным, «Закрыть» прячет в трей → Параметры → Общие.
- Глобальная горячая клавиша Ctrl+Alt+L, автозапуск с Windows → Параметры → Общие.
- Избранное в списке переходов панели задач → правый щелчок по Shelly.
- `Shelly.exe --run "<путь>" [--preset "<имя>"] [--headless]`, `--minimized` → командная строка.
- Сборка `.ps1` в `.exe` → Ctrl+B (только PowerShell).

## Настройки
- Язык (English / Русский), тема, цвет акцента, выбор редактора → Параметры → Общие / Оформление.
- Объём истории и вывода → Параметры → История; обновления → Параметры → Обновления.
- Всё хранится в `launcher-settings.json`, старые файлы настроек загружаются.

## Что Shelly НЕ умеет
- Не песочница: скрипт работает с вашими правами; проверка может пропустить опасное.
- Нет ввода с клавиатуры во встроенном выводе (`pause`, `Read-Host`, `input()`, `set /p` → запускайте в отдельном окне, вывод всё равно попадёт в историю).
- Нет фильтра по типу скрипта в списке (есть только сортировка избранного по типу).
- Нет автопоиска программ своих интерпретаторов.
- Нет формы параметров и сборки `.exe` для Python, Batch и своих.
- Нет запуска от администратора по расписанию; нет синхронизации и облака.
